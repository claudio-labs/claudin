# Feature 6.2 — Bash Output Filter: Tier-1 Follow-ups

Extends [6.1](./6.1-bash-output-filter.md) with filters for the JS/TS toolchain and additional git commands — the most common stack missing from the initial release.

**Status:** Linux/macOS complete. Windows/PowerShell pending (Phase 9).

## What was added

### JS/TS test runners

All five runners collapse clean runs to a single sentinel line. Failures are always preserved via an `unless` guard.

| Command | Reduction |
|---|---|
| `jest` | 98.7% |
| `vitest` | 98.5% |
| `bun test` | 98.2% |
| `mocha` | 97.6% |
| `playwright test` | 98.4% |

### TypeScript compiler

| Command | Reduction | What is stripped |
|---|---|---|
| `tsc` / `tsc --noEmit` | 18.2% | ASCII underline `~~~` lines + trailing `Errors  Files` summary table |

### git diff / git show

| Command | Reduction | What is stripped |
|---|---|---|
| `git diff` | 10.8% | `diff --git a/X b/X` header lines, `index <hash>..<hash>` lines, `\ No newline at end of file` |
| `git show` | 9.4% | Same as above; `Author: Name <email>\nDate: ...` collapsed to one line |

## Cumulative gain (6.1 + 6.2)

31 filters total. Aggregate reduction across all covered commands: **71%**.

## How to toggle

Same as 6.1 — use `/config` → **Bash output filter**, or set `bashOutputFilterEnabled` in `~/.claudio/settings.json`. Both features share the same toggle.

## Pending: Windows / PowerShell (Phase 9)

The following commands are scoped for the next phase but not yet implemented:

- `Get-ChildItem` / `dir` (equivalent of `ls -la`)
- `Get-Process` / `tasklist` (equivalent of `ps aux`)
- `Get-Service`, `Get-WinEvent` / `Get-EventLog`
- `dotnet build` / `dotnet test` / `dotnet restore`
- `msbuild`

PowerShell's tabular auto-formatting and object pipeline require adjustments to `pipeline.ts` before these can be implemented cleanly.

## Run the benchmark

```bash
CLAUDIO_BENCH=1 bun test scripts/profile/bash-filter-gain.test.ts
```

Prints per-command reduction percentages and the aggregate across all 31 filters.
